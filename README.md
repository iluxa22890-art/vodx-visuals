# Vodx Visuals 2.2.0 (Minecraft 1.21.4, Fabric)

Build:  JDK 21 + `./gradlew build`  ->  build/libs/vodxvisuals-2.2.0.jar
(If there is no gradlew: copy `src/`, `gradle.properties`, `build.gradle`, `settings.gradle`
into the official Fabric example mod template, or run `gradle wrapper --gradle-version 8.12`.)

Menu key: Right Shift (rebind in Controls). Search box types instantly; right-click a card
(or click +/-) to open its settings. Config: config/vodxvisuals.properties.
